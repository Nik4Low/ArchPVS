# ArchPVS

Лабораторные работы по Архитектурам Параллельных Вычислительных Систем, магистратура ЛЭТИ 09.04.01 ПИШ САПР микроэлектроники.

## Lab1 — умножение матрицы на вектор

Откройте в Visual Studio файл `Lab1APVS_Un/Lab1APVS_Un.slnx`.

В решении два проекта (у каждого свой `main`):

- `Lab1APVS_Un_seq` — последовательная версия
- `Lab1APVS_Un_par` — MPI-версия

Соберите конфигурацию **Release | x64**. Startup Project переключается правым кликом по проекту.

### Окружение

1. Visual Studio 2022/2026 с рабочей нагрузкой **Desktop development with C++**.
2. Для MPI: [Microsoft MPI](https://www.microsoft.com/en-us/download/details.aspx?id=105289) — и **Runtime**, и **SDK**. После установки должны появиться переменные `MSMPI_INC` и `MSMPI_LIB64`.
3. Если toolset в проекте (`v145`) не совпадает с вашей VS, согласитесь на retarget.

Последовательную программу можно запускать сразу из VS.

Параллельную — через `mpiexec` (уже прописан в настройках отладки проекта):

```text
mpiexec -n 4 Lab1APVS_Un_par.exe 5000 5
```

Аргументы: размер матрицы `M` и число прогонов.
